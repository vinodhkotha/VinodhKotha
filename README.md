# Todo List Web App

A simple, beautiful, and functional todo list application built with HTML, CSS, and JavaScript.

## Features

- ✅ Add new todos
- ✅ Mark todos as complete
- ✅ Delete todos
- ✅ Filter todos (All, Active, Completed)
- ✅ Persistent storage using browser's localStorage
- ✅ Clean and modern UI

## How to Use

1. Open `index.html` in your web browser
2. Type a task in the input field and click "Add" or press Enter
3. Click on a todo to mark it as complete/incomplete
4. Click the "Delete" button to remove a todo
5. Use the filter buttons to view All, Active, or Completed todos

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage API

## Getting Started

Simply open the `index.html` file in any modern web browser. No installation or build process required!
